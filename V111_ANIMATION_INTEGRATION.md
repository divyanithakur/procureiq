# ProcureIQ V111 — Motion Integration

Selected animations integrated without adding a React runtime to the existing Express/vanilla frontend:

- ScrollExpand — homepage product preview
- PixelSwap — homepage decision workflow card
- SpecularButton — primary/action buttons
- SpotlightCard — selected cards and feature surfaces
- Stepper — homepage decision-loop steps
- ThoughtLine — AI analysis states
- PeekRating — existing Help & Support feedback rating

The integration is deliberately additive: existing routes, APIs, authentication, data flows, and button handlers remain intact.

Intentional exclusions: CursorGrid, TargetCursor, MagicRings, LineSidebar, Folder, SlideCommit, SideRays.
