# ProcureIQ V23 — Calm Professional Workspace Update

Updated from the supplied ProcureIQ ZIP based on the requested B2B SaaS UX direction.

## UI / UX
- Restored a light workspace visual language so the workspace feels connected to the public homepage.
- Reduced visual density with calmer spacing, lighter borders, softer shadows and fewer heavy surfaces.
- Reduced dashboard heading/supporting copy across workspace pages.
- Removed the redundant Overview intelligence-strip surface.
- Made Advanced Filters a clean, intentional disclosure control.
- Tightened Opportunities, Analytics, Risk & Evidence, Reports, Billing and Help layouts.
- Kept existing IDs/classes and data-driven functionality intact.

## Interaction fix
- Fixed the account menu toggle so clicking the account button opens it, clicking it again closes it, and clicking outside or pressing Escape closes it.

## Important
- No API keys or environment variables were added.
- Existing application functionality and routes were preserved.
